About CampusSense AI

Smart Campus Navigation System for Bapuji Institute of Engineering and Technology

Problem Identification

Bapuji Institute of Engineering and Technology (BIET), Davangere, has a sprawling campus with multiple departments, administrative buildings, hostels, and facilities spread across a large area. New students, first-time visitors, parents during admission season, and recruiters during placement drives often face difficulty navigating the campus efficiently.

There is no centralized digital navigation tool available for the campus. People rely on asking for directions, which is time-consuming, unreliable, and not accessible for people with mobility challenges. This creates a clear need for an intelligent campus navigation system.

Objective

  • Develop a web-based Smart Campus Navigation System specifically for BIET
  • Implement shortest-path routing using Dijkstra's Algorithm with real campus walking distances
  • Provide an interactive, visual campus graph with all 18 key locations and walking pathways
  • Support wheelchair-accessible route planning for inclusive navigation
  • Integrate an AI-powered assistant for campus FAQs, building information, and route guidance
  • Enable voice-based interaction using browser Speech Recognition API
  • Build a full-stack application with Flask backend and Supabase database

Why Dijkstra's Algorithm?

Dijkstra's Algorithm is one of the most well-known algorithms for finding the shortest path in a weighted graph. It was chosen for CampusSense AI for the following reasons:

  • Guaranteed Optimality: Dijkstra's algorithm always finds the shortest path between any two nodes in a graph with non-negative edge weights
  • Well-Suited for Campus Graphs: Campus navigation maps are sparse, weighted graphs — exactly the type of problem Dijkstra's excels at solving
  • Efficient Performance: With a priority queue (min-heap) implementation, the algorithm runs in O((V + E) log V) time, which is efficient for the scale of a campus graph
  • Accessibility Filtering: The algorithm can easily be modified to skip inaccessible edges, enabling wheelchair-friendly routing without changing the core logic
  • Deterministic Results: Unlike heuristic-based algorithms (e.g., A*), Dijkstra's guarantees the exact shortest path without requiring a heuristic function

Complexity Analysis

The performance of the Dijkstra implementation used in CampusSense AI is analyzed below. With V = number of campus locations (nodes) and E = number of walking pathways (edges):

Time Complexity
O((V + E) log V)

Using a binary min-heap priority queue. Each vertex is extracted once (V log V) and each edge is relaxed once (E log V).

Space Complexity
O(V)

Storing distance array, predecessor array, visited set, and the priority queue — all proportional to the number of vertices.

For the BIET campus graph with V = 18 locations and E = 25 pathways, the algorithm executes in microseconds, providing instant results for any source-destination pair.

Implementation Methodology

  • Frontend: HTML5, CSS3 (glassmorphism dark theme), and JavaScript with Cytoscape.js for interactive graph visualization
  • Backend: Python Flask serving REST API endpoints for route computation, location data, and AI chat
  • Database: Supabase (PostgreSQL) for persistent campus location and route data, with in-memory fallback
  • Algorithm: Custom Dijkstra implementation in Python (server-side) with priority queue optimization
  • AI Assistant: Hugging Face Inference API integration with campus-aware system prompt and keyword-matching fallback
  • Voice: Browser Speech Recognition API for voice input, Web Speech Synthesis API for voice output
  • Graph Data: 18 campus locations modeled as nodes with 25 bidirectional weighted edges representing walking pathways
  • Accessibility: Wheelchair-accessible routing mode that filters out edges marked as inaccessible (e.g., stairs)
